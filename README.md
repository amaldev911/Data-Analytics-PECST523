**This is the repository for submitting your First Data Analytics assignment** _(Simple ML model)_

## How to Submit 

1. **Fork this Repo**
Go to [Top Of this repo](https://github.com/prawmathean/Data-Analytics-PECST523)  and click the **Fork** button _(top right)_
2. Clone the repo you just forked 
```bash
git clone https://github.com/YOUR_USERNAME/repo-name.git
cd Data-Analytics-PECST523
```
_Replace the url with the url of your forked repo_

3. **Create a folder** inside this repo with your Name and registeration number _(for example : `prajwal-24cs089`)_
4. **Move your code** _(and dataset if applicable)_ to this folder you just created
5. **Commit and Push**
```bash
git add .
git commit -m "Assignment Submission"
git push origin main
```
_(you can change the commit message as per your wish_

6. **Open a Pull Request**
- Go back to your fork on GitHub.
- Click Contribute $\rightarrow$ Open Pull Request.
- Set the title as: [Assignment Submission] - Your Name (registeration Number).
- Submit the PR!

_Please Don't edit or modify other student's folder or edit their code._
